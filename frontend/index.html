Process Flow

How ChildNutri AI Works

A streamlined pipeline from data collection to actionable health insights.

1
📥 Data Collection
Healthcare worker enters infant details — age, weight, height, MUAC (Mid-Upper Arm Circumference) — or uploads a photo for visual analysis.
2
🧠 AI Processing
The trained machine learning model processes the input data, compares it against WHO growth standards, and runs classification algorithms.
3
🔍 Malnourishment Classification
The system classifies the infant's nutritional status into: Normal, Stunted, Wasted, Underweight, or Severely Acute Malnourished (SAM).
4
📄 Report Generation
A detailed report is generated with risk scores, visual charts, condition explanation, and tailored dietary and medical recommendations.
5
🏥 Intervention & Follow-Up
Healthcare providers receive alerts and scheduled follow-up reminders. Severe cases are escalated to doctors or nutritional programs automatically.
