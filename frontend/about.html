About ChildNutriAI

A quick overview of what the project does, why it exists, and how it's built — for anyone reviewing it for the first time.

Project introduction

ChildNutriAI is an AI-assisted screening tool for child malnutrition. A health worker registers a child, uploads a face and full-body photo, and receives a nutritional-risk prediction with practical recommendations — designed for use in community health centers and field screening camps where lab-based diagnosis isn't always available.

Objectives

  • Enable fast, low-cost malnutrition screening using a photo and basic measurements.
  • Classify each child into Normal, Mild, Moderate, or Severe malnutrition.
  • Give health workers clear, actionable nutrition recommendations.
  • Track a child's growth over repeat visits, not just a single snapshot.

Technologies

HTML / CSS / JS Python Flask / FastAPI TensorFlow / PyTorch OpenCV Pandas SQLite

Algorithms

  • CNN (transfer-learned, e.g. MobileNet/EfficientNet) for visual assessment from photos.
  • Gradient boosting / shallow MLP on anthropometric data (age, height, weight, MUAC).
  • WHO growth-standard z-score calculations as engineered features.
  • Late-fusion ensemble combining the image and tabular models into one prediction.
