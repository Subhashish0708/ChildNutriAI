# models/

Trained model weights/checkpoints go here (not yet populated).

Example: `efficientnet_b0_visual.pt` (image branch), `xgboost_anthropometric.json` (numerical branch), `fusion_classifier_v1.pt` (final FC + softmax layer), plus a `metadata.json` per model recording training date, dataset version, and validation metrics. Keep large binaries out of version control — use Git LFS or external storage instead.
